# api-game-zone
API de Game Zone

## Instrucciones
  1. Instalar el programa Laragon: https://laragon.org/
  2. Ya instalado, presionar "Iniciar Todo"
  3. Ir a "Base de datos"
  4. Rellenar con contraseña si es necesario
  5. Ir a consulta e insertar el siguiente script: "CREATE DATABASE IF NOT EXISTS db_game_zone"
  6. Ahora abrir el backend con algun IDE y iniciarlo
